# Footwear Flow Hub

Build a complete full-stack web platform for a Wholesale Footwear Distribution Business. Features needed: 1) A clean public corporate website with a footwear catalog (shoes categorized by type, bulk pricing, and filters). 2) A Dealer Portal where wholesale buyers can log in, place bulk orders, and view order status. 3) An Administrative Dashboard for inventory management (adding/updating shoe stock and viewing simple sales analytics). 4) An AI Product Finder tool that allows users to ask for shoe recommendations in natural language.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
